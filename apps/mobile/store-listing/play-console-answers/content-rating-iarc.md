# Content rating (IARC) questionnaire — recommended answers

Play Console ▸ App content ▸ **Content ratings** ▸ Start questionnaire

**Email address:** use the developer contact email (e.g. `tilcer@oksystem.cz`).

**Category:** YarnLog is not a game. Choose the app category
**"Reference, News, or Educational"** *or* **"Utility, Productivity, Communication, or Other"** —
either fits a craft/productivity tool. (If unsure, pick *Utility, Productivity, Communication, or Other*.)

Answer every content question **No** — the app is a private, offline knitting/crochet tracker
with no objectionable content and no social features.

| Topic | Answer |
|---|---|
| Violence (cartoon, fantasy, realistic, graphic) | **No** |
| Blood / gore | **No** |
| Sexual content or nudity | **No** |
| Sexual innuendo / suggestive content | **No** |
| Profanity or crude humor | **No** |
| References to alcohol, tobacco, or drugs | **No** |
| Simulated gambling | **No** |
| Real gambling (real-money) | **No** |
| Frightening or disturbing content | **No** |
| Controlled substance references | **No** |

### Expected outcome

With all answers **No**, IARC returns the lowest ratings in every region, e.g.:

- ESRB (Americas): **Everyone**
- PEGI (Europe): **PEGI 3**
- USK (Germany): **USK 0**
- ClassInd, etc.: equivalent "all ages"

Submit the questionnaire to generate and apply the ratings. Re-run it only if app content
materially changes (it won't for a tracker like this).
